# Therac25 Configuration Management Project

This project demonstrates the use of configuration management using GitHub.

## Features
- Version control using GitHub
- Branching and merging
- File tracking (config.json, app.py)

## Files
- config.json: Stores application configuration
- app.py: Simple Python file
- README.md: Project documentation

## Workflow
- Created repository
- Added files and commits
- Created feature branch
- Made changes and merged using pull request

This project shows basic CM practices.
